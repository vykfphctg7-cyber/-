# 项目工作区

仅在此提交可公开项目；非公开项目请在私有仓库按相同结构建立。

新建 `项目代号_项目简称/`，按需创建下列目录，并从 templates 复制所需模板。不要修改通用模板来保存单个项目的正文。

```text
DEMO_项目简称/
  README.md                 项目入口：范围、负责人、当前版本及各文档链接
  01_development/           立项、人物、精品剧总纲
  02_outlines/              分集大纲与节奏设计
  03_scripts/               EP001_剧本.md
  04_storyboards/           EP001_分镜.md、镜头提示词卡
  05_assets/                资产台账、连续性记录、批准公开的轻量参考
  06_handoff/               交接、变更与验收
  99_archive/               已作废但需说明的交付清单；正文历史优先用 Git
```

不要预建未使用的空目录；Git 不记录空目录。首份文档进入后目录自然建立。
项目 README 至少记录项目状态、当前确认版、文档入口、下一里程碑、待决事项和审核人。
