# 短剧创作资料库

统一管理红果短剧、精品剧、AIGC 分镜与项目交接资料。从立项、人物与大纲，到逐集剧本、镜头制作和交付，使用同一套项目编号关联。

> 本库为内部创作方法与模板，不代表红果或其他平台官方投稿标准。集数、时长、题材边界、格式与提交材料以项目确认的最新要求为准，并在立项表记录来源及确认日期。
> 本仓库公开可见：仅提交可公开模板、原创演示或已获授权的内容。未公开剧本、合同、个人信息和商业素材请放在受控私有空间；不要在公开文档中写入其访问凭证。

## 目录

```text
docs/                         创作规范与审稿清单
templates/
  common/                     立项、人物、分集大纲
  hongguo/                    红果短剧单集剧本与节奏表
  premium/                    精品剧总纲、单集剧本
  aigc/                       分镜表、提示词、资产与连续性
  handoff/                    交接、变更与验收
projects/                     项目工作区约定（仅可公开内容）
examples/                     虚构片段示例
```

## 第一个项目怎么开始

1. 阅读[协作规范](docs/创作与版本规范.md)，用项目代号如 `DEMO` 建目录，遵循[项目工作区说明](projects/README.md)。
2. 复制[立项简报](templates/common/立项简报.md)、[人物小传](templates/common/人物小传.md)、[分集大纲](templates/common/分集大纲.md)到项目对应目录，填写目标受众、故事引擎、集数时长和权属。
3. 红果方向使用[单集模板](templates/hongguo/单集剧本.md)和[节奏表](templates/hongguo/节奏设计.md)；精品剧方向先写[项目总纲](templates/premium/项目总纲.md)，再写[单集剧本](templates/premium/单集剧本.md)。
4. 剧本审核后，复制[AIGC 分镜](templates/aigc/分镜表.md)、[提示词卡](templates/aigc/镜头提示词卡.md)和[资产表](templates/aigc/资产与连续性.md)，按场次和镜号关联素材。
5. 按[审稿清单](docs/审稿与交付清单.md)自检，完成[项目交接](templates/handoff/项目交接.md)、[变更记录](templates/handoff/变更记录.md)与[验收记录](templates/handoff/验收记录.md)。

模板中的 `[待填]` 需替换；不适用项填写“不适用 + 原因”。模板内建议均可根据项目调整。先看[虚构示例](examples/DEMO_片段示例.md)了解从大纲到镜头的串联方式。

## 协作和版本

使用 UTF-8 Markdown，表格可直接复制到协作工具。主分支保存审核确认版本；多人协作用项目分支和 Pull Request 讨论修改，记录变更原因与影响集数。文件名保持稳定，版本写在文档头部，历史通过 Git 保存。审核通过不等于平台通过，提交和回执在交接表单独记录。
